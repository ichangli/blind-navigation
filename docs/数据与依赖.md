# 数据与依赖

## 随仓库提供的数据

| 路径 | 内容 |
|---|---|
| shenzhen_data/processed/buildings | 福田建筑轮廓与高度/分类，8,897 栋 |
| shenzhen_data/processed/support | 公交、地铁出入口、医院、公厕、公园等支撑数据 |
| datasets/basemap | 本地深蓝底图的道路、水域、绿地、背景与注记 |

原先位于 E:/GIS_data 的必要数据已整理到 datasets。本机原路径只在历史说明和制作脚本中保留，已构建的 Pages 演示不依赖该路径。

建筑、路网和底图包含 OpenStreetMap 衍生数据。© OpenStreetMap contributors；[版权与 ODbL 说明](https://www.openstreetmap.org/copyright)。本仓库保留原数据报告中的来源字段。设施包括深圳公开站点及服务设施整理数据，参见 shenzhen_data/processed 的报告、CSV 和各 GeoJSON 的 source 字段。高德地理编码缓存、真实上报照片和用户数据库不随仓库公开。

建筑高度中包含根据类别、面积或楼层估算的值，不能用于测量或工程精度用途。道路属性包含未知状态，颜色与权重仅反映已有字段。

## 路线案例的处理

离线脚本将 GDB 多部件线分别处理，按端点构建案例图，排除 prohibited 道路，并用投影坐标几何长度重新计算案例成本。已有数据中两条分割边的成本继承了原整段值；案例导出重新按几何和原公式计算，原始 GDB 保持不变。manifest 记录这项处理。

案例成本：行走分钟 = 米制几何长度 / 72；权重成本 = 行走分钟 × (1 + risk_score × 0.12)，台阶另加 2 分钟。权重成本不是预计实际行走时间。生成的路线不等同于原版 NAServer 的完整求解结果，也不代表现场安全通行结论。

- 后端依赖见 backend/requirements.txt；测试依赖见 package.json 和 package-lock.json。

在线演示使用本地数据，不请求 GeoScene，不使用收费底图、地理编码或路径服务；原版后端接口及外部服务接入代码仍完整保存。
