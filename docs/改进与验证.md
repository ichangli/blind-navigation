# 2026-11-03 本地改进与验证

本次改进针对 github-release 发布源码；各项验证范围与限制记录如下。

## 安全与运行方式

事件列表使用 DOM 文本节点与监听器；详情及事件弹窗统一转义，不再在 Pages 构建阶段临时补转义。用户名新增 1–32 字符限制。正式启动必须配置独立 JWT 密钥与管理员密码，并拒绝仍用演示密码的已有管理员；仅显式 demo 模式灌入样例业务数据。本机启动器仍仅绑定 127.0.0.1。

本轮 14 项 Node 测试与 5 项 Python 安全测试通过。Node 回归覆盖源文件和 Pages 产物的恶意字段、恶意事件 ID 以及查看/删除按钮的正确 ID 传递，不向远端发送数据。Python 回归覆盖默认配置拒绝、正式与演示配置、已有弱密码管理员拒绝和恶意注册名拒绝。CI 加入该后端安全回归。

登录限流、完整会话策略和所有历史后端测试的 CI 整合仍未完成。直接依赖按本机验证版本固定，不宣称所有跨平台间接依赖均已锁定。

## 可访问性

核心静态与动态图层开关、专题和筛选项改为原生按钮，状态同步 aria-pressed；登录字段关联 label。删除对话框补 Escape、Tab 焦点圈定与取消后恢复焦点。路线延伸、镜头移动和 CSS 响应减少动画设置。本机独立 Chrome 验证道路开关的 Enter 操作、删除对话框焦点与 Escape，未进行屏幕阅读器或真实视障用户验收。

## 路网与发布体积

独立无登录 Chrome、空缓存、1440×1000、本机 HTTP 无压缩服务器。原流程在三维初始化时请求 network-display.geojson，记录 decodedBodySize=19,316,423 字节，transferSize=19,316,723 字节（含响应头），本机耗时约 316.5ms。此耗时不代表国内或海外公网表现。

修改后：三维就绪时无该路网请求；键盘首次开启道路图层后请求一次，关闭再打开复用已有图层。专题渲染切换成功，三维白模、水域及底图真实显示，未捕获页面脚本错误。未简化或改写道路几何与原 GDB。Pages 包排除运行时不用的 .d.ts，构建结果从 106.87 MiB 降至 101.19 MiB；这些类型声明原先并不在浏览器首屏下载。

## 后续工程化

本批先建立事件渲染安全边界与测试、明确演示适配边界。进一步抽离 API/数据访问、事件组件和地图生命周期，以及是否迁移 Vite，需继续逐模块验证原版与 Pages；本批未声称完成整站模块化。许可证与 GitHub Topics 保持原样，未代替作者选择授权或修改远端元数据。

## 可重复的浏览器检查

先构建并以 `python -m http.server 8877 --bind 127.0.0.1 --directory site-demo` 启动本地服务。在已安装 Playwright 与 Chrome 的环境运行 `node tools/verify_browser.cjs http://127.0.0.1:8877/`。可用 PLAYWRIGHT_MODULE 指定已有 Playwright 包路径；可选第三个命令行参数为截图输出路径。该检查创建独立无登录浏览器，不使用现有 Chrome 用户数据，不提交或删除事件。
