# 静态演示包

这是当前 Pages 演示的下载版，与旧的 BlindNavigationDemo 业务后端 EXE 分开发布。Windows x64 包包含本机静态 HTTP 启动器、完整页面与本地地图数据。无需另外安装 Python、GeoScene、PostgreSQL 或其他数据库服务；启动器没有业务 API，不会读写 SQLite。

## 使用

从 GitHub Release 下载 ZIP，完整解压后双击“启动演示.bat”。浏览器访问 http://127.0.0.1:8877/，结束时关闭控制台。不要从压缩软件内启动，不要直接双击 HTML。端口被占用时可关闭旧演示，或运行 `BlindNavigationStaticDemo.exe --port 8878`。只绑定本机地址，其他设备不能访问。

数据在浏览器 IndexedDB/localStorage 中持久化。更换浏览器、端口或清理网站数据会影响存储；点击顶部“重置演示”可恢复样例。地图和路线案例不依赖网络；主动打开 GitHub 和来源说明链接需要联网。路线为三个固定案例，尚未现场核实。

## 构建

在 Windows x64 的 Python 环境安装 PyInstaller，仓库根目录执行：

```powershell
python tools/build_static_release.py --version v1.0.0 --output dist/static-release-v1.0.0
```

脚本先重建 Pages 产物，再仅复制静态网站、许可、说明和静态启动器，不读取 backend/.env。已有输出不会覆盖。输出 ZIP、SHA256 校验文件和包内逐文件 MANIFEST.json；manifest 记录制作时的源码提交。EXE 由 PyInstaller 构建，不包含完整 FastAPI 业务程序。
